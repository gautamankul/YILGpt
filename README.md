# YILGpt
1. `uvicorn main:app --reload` to start the server.
2. Open `http://127.0.0.1:8000` in your browser.
3. Click on the "Try it out" button to test the API.
4. You can also use tools like Postman or curl to send requests to the API endpoints
## API Endpoints
- `POST /chat`: Send a message to the chatbot and receive a response.
- `POST /chat_stream`: Send a message to the chatbot and receive a streaming response.
- `POST /chat_stream_with_history`: Send a message along with the conversation history and receive
    a streaming response.
